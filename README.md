# Python Sets

## Explanation

A set is an unordered collection of unique elements in Python. Sets automatically remove duplicate values.

Sets are created using curly braces `{}`.

## Problem Statement

Write a Python program that creates sets and demonstrates adding, removing, and performing basic set operations.

## Features

* Creates sets
* Removes duplicate elements
* Adds elements using `add()`
* Removes elements using `remove()`
* Demonstrates union
* Demonstrates intersection
* Demonstrates difference

## How It Works

The program creates two sets containing numbers and performs common set operations.

### Set Operations

* `union()` combines all unique elements.
* `intersection()` returns common elements.
* `difference()` returns elements present in one set but not the other.

## Technologies Used

* Python 3

## Program Flow

1. Start the program.
2. Create two sets.
3. Display the sets.
4. Add an element.
5. Remove an element.
6. Perform union.
7. Perform intersection.
8. Perform difference.
9. Display the results.
10. End the program.
